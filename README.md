# webmake-v2

`webmake` の改良版サイトです。GitHub Pages で公開可能です。

## 特徴
- モダンなダークテーマデザイン
- レスポンシブ対応
- CSS アニメーション（fade-in、hover効果）
- Instagram リンクセクション（ユーザーネームを更新してください）
- ハンバーガーメニュー（バニラJS）

## GitHub Pages の設定
1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: main / root
4. Save

## 画像について
元の `webmake` リポジトリから `assets/images` フォルダをコピーしてください。
パスは元と同じ構成になっています。

## Instagram
`index.html` 内の `YOUR_ACCOUNT_1` と `YOUR_ACCOUNT_2` を実際のユーザーネームに変更してください。
